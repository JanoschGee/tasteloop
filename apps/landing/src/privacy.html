This website is a static page. It has no forms, no accounts, no cookies, no tracking and no third-party fonts or scripts. We do not collect personal data ourselves. The only data processed when you visit is what any web server needs to deliver a page.

Tasteloop software

Tasteloop is open-source software that you run on your own machine with your own accounts and API keys. Data you process with it (images, voice notes, notes, brand guides) stays with you and the services you choose to connect (for example Telegram, Anthropic, Obsidian). We do not receive or process any of it.
